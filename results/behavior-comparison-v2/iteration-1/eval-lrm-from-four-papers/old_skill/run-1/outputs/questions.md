# Questions before starting

1. Which field or discipline does this research sit in (e.g., education, psychology, computer science, nursing, business)?
2. What is your research title or topic, so I can judge how relevant each of the four papers is?
3. Do you want only the Literature Review Matrix built from these four papers, or should I also search for more papers (a postgraduate-level matrix usually has 15-20)?
4. Which publication years should count? By default, papers must be from the last 5 years (2021 or later).
5. Where should I save the PDF?
