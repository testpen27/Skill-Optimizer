## Notes on the choices
- I used five concepts instead of the usual four because your topic has two filters, older adults and rural, that both need to apply. If narrow returns too few papers, drop the rural block first (that's the focused tier), then add more place names to the Malaysia block.
- The Malaysia block includes state names, "Orang Asli", "Klinik Kesihatan", "Klinik Desa" and MySejahtera. Many studies name the state or the clinic rather than the country. This block filters on topic, not on author affiliation.
- For the rural block, I wrote "remote area*", "remote communit*" and similar phrases instead of a bare `remote`. A bare `remote` would match "remote consultation" from the telemedicine block and let non-rural papers through.
- `aged` and `senior*` widen the older-adults block (Scopus indexes the keyword "Aged" for clinical studies). If the focused tier is noisy, check the first 50 records before deciding whether to drop them.
- Your 60+ cut-off can't be set in a search string. Apply it at screening.
