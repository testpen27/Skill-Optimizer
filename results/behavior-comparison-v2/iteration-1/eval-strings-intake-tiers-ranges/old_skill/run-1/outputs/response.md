## Notes
- **Which tier to use:** I expect narrow (rural + Malaysia) to return very few records, maybe only a handful. Balanced is likely your main search. Broad is a fallback if balanced is too thin. As a rough guide, 100 to 2,000 records is workable for screening. Under about 50, go one tier broader.
- **Built in:** `utili*ation` and `behavio*ral` catch both UK and US spelling. Phrases end in `*` (e.g. `"older adult*"`) so Web of Science also finds plurals. State names (Sabah, Sarawak, Kelantan and so on), FELDA, kampung and Orang Asli catch studies that name the place but not "Malaysia".
- **Not limited:** document type and language. You didn't specify these, so filter them on the results page (e.g. Article, English) and record the filters in your methods.
